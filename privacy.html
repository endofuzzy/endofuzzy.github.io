プライバシーポリシー

shorts-bot（以下「本ツール」）は、運営者が自分の YouTube チャンネルへ動画を投稿するための個人用ツールです。運営者以外の利用者はいません。

1. 使う情報

本ツールは YouTube API Services を利用し、運営者本人の許可（OAuth）のもとで、次のことだけを行います。

  • 運営者のチャンネルへ動画・サムネイル・字幕をアップロードする
  • 運営者のチャンネルの再生回数・登録者数・視聴維持率を読み取る（運営者への報告のため）

2. 保存と共有

  • 取得した情報は、運営者の手元の機器にだけ保存します。
  • 第三者への提供・販売・広告への利用はしません。
  • 運営者以外の YouTube ユーザーの情報は取得しません。

3. 許可の取り消し

Google アカウントの サードパーティのアクセス から、いつでも本ツールへの許可を取り消せます。

4. 関連する規約

本ツールは YouTube API Services を利用しています。利用にあたっては YouTube 利用規約 と Google プライバシー ポリシー が適用されます。
