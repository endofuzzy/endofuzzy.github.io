MD Link Clip プライバシーポリシー

MD Link Clip（以下「本拡張機能」）は、開いているページのタイトルと URL を Markdown などの形式でクリップボードにコピーするブラウザ拡張機能です。本拡張機能は、利用者の個人情報やデータを収集・送信しません。

1. 収集・送信しないもの

閲覧履歴、入力内容、ページの内容、利用状況。本拡張機能は外部のサーバーと一切通信しません。広告・解析・トラッキングの仕組みもありません。

2. ブラウザの中だけで扱うもの

以下は、利用者がアイコンのクリック・ショートカットキー・右クリックメニューで操作したときにだけ読み取り、クリップボードにコピーする文字列を作るためにのみ使います。コピーが終われば保存しません。

  • 開いているタブのタイトルと URL
  • 右クリックしたリンクの URL と表示文言
  • ページ上で選択しているテキスト（引用を使うときのみ）

3. 保存するもの

  • コピー形式とオプションの設定（chrome.storage.local）。利用者の端末内にのみ保存されます。

本拡張機能の開発者がこれらを見ることはできません。本拡張機能を削除すると、保存したものも削除されます。

4. 第三者への提供

集めていないため、提供・販売もしません。

5. 変更

このポリシーを変更する場合は、このページを更新します。

制定日: 2026年10月15日

MD Link Clip Privacy Policy

MD Link Clip ("the extension") is a browser extension that copies the title and URL of the open page to the clipboard as Markdown and other formats. It does not collect or transmit any personal information or user data.

1. Not collected or sent

Browsing history, anything you type, page content, or usage. The extension never communicates with any external server. It contains no ads, analytics or tracking.

2. Handled only inside your browser

The following is read only when you act through the toolbar icon, the keyboard shortcut or the context menu, and only to build the text copied to the clipboard. It is not stored after the copy.

  • The title and URL of the open tab
  • The URL and visible text of a link you right-click
  • Text you have selected on the page (only when quoting)

3. Stored

  • Your copy format and option settings (chrome.storage.local), kept only on your device.

The developer cannot see them. Removing the extension deletes them.

4. Sharing with third parties

None, since nothing is collected. Nothing is sold.

5. Changes

Any change to this policy will be published on this page.
